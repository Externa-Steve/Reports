# Rapports de clients anonymisés

### Steve -- sécurité informatique

Je bascule dans la cybersécurité par passion, pas par hasard : comprendre
comment les choses se cassent pour mieux les protéger, ça m'anime depuis
un moment. Aujourd'hui je construis **Externa**, mon activité de sécurité
informatique pour les petites structures qui n'ont souvent personne pour
veiller sur elles.

**Ce que je fais déjà**
- Audits de sécurité réseau et postes de travail (reconnaissance, Nmap, durcissement)
- Restitution claire : je traduis le technique pour des non-initiés, sans les noyer
- Accompagnement d'apprenants en cybersécurité comme assistant pédagogique (Jedha)

**Ce que j'approfondis en ce moment**
- Analyse de risques méthode EBIOS RM (ANSSI)
- Conformité et gouvernance (ISO 27001, NIS2)
- Pentest web et API — mon axe de spécialisation à long terme

**Ce que je cherche**
Collaborer avec des ESN, cabinets ou équipes sécurité prêts à faire grandir
un profil sérieux et motivé. Je ne prétends pas tout savoir : j'apprends vite
et je travaille honnêtement.

Vous retrouverez ici les études de cas (clients anonymisés) TPE/PME et entités soumises au NIS2.
Les cas fictifs seront annoncés dans les titres. 

Bonne lecture
