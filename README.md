# Études de cas Externa

> [!NOTE]
> Clients **anonymisés**. Les cas fictifs, s'il y en a, sont signalés dans leur titre.

## Qui je suis

Steve, sécurité informatique.

Je bascule dans la cybersécurité par passion : comprendre comment les choses se cassent pour mieux les protéger.
Je construis **Externa**, une activité de sécurité informatique pour les petites structures qui n'ont souvent personne pour veiller sur elles.

## Ce que je fais déjà

- Audits de sécurité réseau et postes de travail (reconnaissance, Nmap, durcissement)
- Restitution claire : je traduis le technique pour des non-initiés, sans les noyer
- Ancien assistant pédagogique en cybersécurité chez Jedha (voir le dépôt [Jedha](https://github.com/Externa-Steve/Jedha))

## Ce que j'approfondis

- Analyse de risques : méthode EBIOS RM (ANSSI)
- Conformité et gouvernance : ISO 27001, NIS2
- Pentest web et API : mon axe de spécialisation à long terme

## Ce que je cherche

Collaborer avec des ESN, cabinets ou équipes sécurité prêts à faire grandir un profil sérieux et motivé.
Je ne prétends pas tout savoir : j'apprends vite et je travaille honnêtement.
